# zsports

Client-facing Meta ads reports for **Shah Sports Tech Private Limited** (Z-Bat).

| Report | Period | Live |
|---|---|---|
| AI Bat Fit Quiz — Website Leads | 8–12 Sep 2026, updated live | [index.html](https://lenkasacademy-pixel.github.io/zsports/) |

Source: Meta Ads API, ad account `1811409506889048` (zbats). Figures are in the
advertiser's time zone, currency INR. Updated as the campaign runs.

Pages are self-contained single HTML files — no dependencies beyond Google
Fonts. `index.html` is the **client build**: it is generated from a fuller
internal version by cutting the "What to change next" recommendation cards and
their CSS, so those never reach the client link. Quiz and cart figures come
from the store pixel `1380826504029254` and count all site traffic, not only
visitors from ads.
